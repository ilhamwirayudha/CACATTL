# Folder Dokumen Referensi & Perhitungan Simulasi

Folder ini (`references/`) digunakan untuk menyimpan file dokumen referensi, dokumen formula, serta file Excel (`.xlsx` / `.xls`) yang berisi acuan perhitungan analitis dan logika simulasi untuk dashboard **CACA**.

---

### Cara Penggunaan:
1. Taruh file Excel perhitungan simulasi Anda di dalam folder ini.
2. Anda bisa memberi nama file bebas (contoh: `perhitungan_simulasi.xlsx` atau `acuan_simulasi_caca.xlsx`).
3. Setelah file dimasukkan, beritahu saya agar isi tabel, rumus antar sel, dan logikanya dapat langsung dibaca dan dianalisis.
